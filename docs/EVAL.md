# 意味検索の評価

意味検索の設定（モデル・チャンクの大きさ・閾値など）を変えるたびに、同じ問題で数字を比べるための記録。

## 評価セット

- 文章 30件（`tests/eval/dataset.js`。自作）
- 質問 36件：言い換え 29件／言葉がそのまま入る 7件。それぞれ正解の文章が1つ決まっている
- 関係ない質問 6件：どの文章とも無関係。「関係ない」と捨てる閾値を決めるための確認用

## 実行のしかた

1. 公開URL（https）の `tests/eval.html` を開く（初回は約120MBのモデルを取得する）
2. 「実行」を押す。結果が画面に出る
3. 下の表に、日付・端末・設定と一緒に転記する

「疑似モデルで仕組みだけ確認」は、実モデルの代わりに文字2-gramのハッシュを使う。順位の数字は参考にならず、評価の仕組みが動くことの確認用。

## 見る数字

| 指標 | 意味 |
|---|---|
| 1位 | 正解の文章が1位に出た割合 |
| 3位以内／5位以内 | 上位に入った割合 |
| MRR | 正解の順位の逆数の平均（1.0が最高。出なければ0） |
| 近さの分布 | 正解が1位のときの意味検索の近さと、関係ない質問の最高の近さ。閾値はこの間に置く |
