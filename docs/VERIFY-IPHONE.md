# iPhone での確認手順（v0.12.1）

この手順で確かめた結果をもとに、既定のモデルと動かし方を決める。結果を送ってもらうまで、どれも「動作確認済み」とは書かない。

## 準備

1. アプリを開き、メニューの「最新版を確認する」を押す。バージョンが **0.12.1** になっていることを確かめる。
2. 念のため、メニューの「書き出す」でバックアップを取る。この版は、保存した知識を消す処理をしない。それでも念のため取っておく。
3. Wi‑Fi につなぐ。モデルは初回だけダウンロードする（230〜470MB）。

## A. 試験室で、方式を決める

試験室を開く：https://sin-skull.github.io/ai/lab/

- アプリと同じ入口（Safari、またはホーム画面のアプリ）で開くと、アプリとモデルの保存分を共有する。
- ここで落ちても、アプリの記憶には影響しない。

| 順 | モデル | 動かし方 | 押すボタン | 見ること |
|---|---|---|---|---|
| A1 | 配管テスト用（極小） | CPUだけ・実行用ファイルは「自動」（互換版） | 全部を順に試す | 仕組みが iPhone で動くか。答えは意味のない英字で正常。v0.12.0 の速い版では初期化で止まった |
| A2 | LFM2 350M | CPUだけ | 全部を順に試す | 本命。落ちないか、5つの試験が全部通るか |
| A3 | LFM2 350M | 分担（半分をGPU） | 全部を順に試す | A2 が通ったら試す |
| A4 | LFM2 350M | GPU | 全部を順に試す | A3 が通ったら試す |
| A5 | LFM2 350M | CPUだけ ＋「検索モデルとの入れ替えも試す」にチェック | 全部を順に試す | 意味検索と回答モデルを交互に載せても落ちないか |
| A6 | Gemma 3 270M／Qwen2.5 0.5B | CPUだけ | 全部を順に試す | 比較用（時間があれば） |

- 試験の中身は、順に次の5つ：読み込み、短い答え3回、検索と連携5問、長い資料（約1700字を分けて読む）、連続10問（続きの質問を含む）。
- 動かし方やモデルを変えるときは、「止める」→ 選び直し、の順にする。選び直すと、前のモデルは自動で外れる。
- **落ちたら**：試験室を開き直す。上に「前回、○○の途中でページが強制終了しました」と出る。落ちた条件は、くり返さずに次へ進む。
- それぞれ試し終えたら「結果をコピー」を押し、ここに貼り付けて送る。結果には、端末の情報、各試験の結果（最初の文字までの秒数、速さ、品質）、段階の記録が入る。

## B. アプリで確かめる（完成条件）

A で落ちなかった、いちばん良い条件をアプリに設定する。

1. メニュー →「設定と保存」→ 回答モデルの「モデル」と「動かし方」を選ぶ → 「有効にする」。
2. 知識を用意する。質問欄の下の「知らないことは自動で調べる」をオンにして「光合成とは？」を送るか、文章を貼って保存する。
3. 次の10問を、1つずつ続けて送る（短い質問を10回連続）。

```
光合成とは？
それはどこで行われるの？
光合成で何ができるの？
植物はどうやって光から栄養を作るの？
葉が緑なのはなぜ？
光合成に必要なものは？
それって夜もできるの？
二酸化炭素はどうなるの？
酸素はどこへ行くの？
光合成を一言でいうと？
```

4. アプリを完全に閉じて（アプリ切り替えで上にスワイプ）、開き直す。自動で読み込みが終わったら、もう一度1問送る。
5. 機内モードにして（またはアプリのオフラインモードで）開き直し、1問送る。

**完成条件**：1〜5 が、落ちずに最後まで通ること。根拠付きで答えること。

## 落ちたとき

- 開き直すと「前回、『○○』の途中でアプリが強制終了したようです」と出る。今回はモデルを自動で読み込まない（同じ処理をくり返さない）。
- 「診断の記録を見る」→「コピー」で、段階の記録を送る。
  - 記録には段階名、字数、何問目か、方式だけが入る。**質問の本文は入らない。**
- 同じ条件で2回落ちると、動かし方が1段軽くなる（GPU → 分担 → CPU）。いちばん軽い条件でも3回落ちると、回答モデルをオフにする。保存した単語・文章・バックアップには触れない。

## 送ってほしいもの

- 試験室の「結果をコピー」（A1〜A5 のそれぞれ）
- アプリで落ちた場合：案内の文面と、「診断の記録」のコピー
- B の 1〜5 がどこまで通ったか
