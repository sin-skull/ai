# ai

オフラインでも使える、自作のAIアシスタント。

**頭脳は共通、記憶は各自。** 検索で知識を蓄え、オフラインでは蓄えた知識だけで答える。蓄積したデータは各自の端末の中にだけ置く。

- ロードマップ: [docs/ROADMAP.md](docs/ROADMAP.md)
- データ設計: [docs/DATA_DESIGN.md](docs/DATA_DESIGN.md)

## 設計原則

1. 記憶は端末内だけに置く。サーバーに個人データを溜めない。
2. 共有するのは読み取り専用の部品（アプリ本体、埋め込みモデル、百科事典パック）だけ。
3. 何を残すかは常に自分で決める。保存前に確認し、後から消せる。
4. 単語は重複なしの辞書に統合し、文章は出典付きで丸ごと保存して1件ずつ削除できる。
5. 評価はユーザーの操作（👍/👎）を主にし、言葉の感情分析は補助にする。
6. 検索は成長の源。答えられなかった質問は未回答キューに残し、次のオンライン時に調べる。
7. 見た目は手作り感を優先し、テンプレ的なAI臭さを避ける。

## 技術スタック（初期案）

| 役割 | 選択 |
| --- | --- |
| アプリ形態 | 単一HTML（PWA） |
| 記憶の保存 | IndexedDB |
| オフライン化 | Service Worker + manifest |
| キーワード検索 | 自前の文字n-gram転置インデックス |
| 意味検索 | Transformers.js + 多言語埋め込み（e5-small級） |
| 回答生成 | WebLLM / transformers.js（1〜3B級） |
| 直接読める検索元 | Wikipedia API |
| 任意URL・検索API | Cloudflare Workers（無料枠）の中継 |
| バックアップ | JSONの書き出し・読み込み（自動クラウド同期は入れない） |

## 状態

フェーズ1-A（単語辞書）まで完了。進め方は [docs/ROADMAP.md](docs/ROADMAP.md) を参照。

## 使い方

- 「AI = 人工知能」と送ると覚える（「単語：意味」でもよい）
- 「AIとは？」「AI」と送ると、覚えている意味を答える
- 「AIは人工知能」のような文は、確認してから覚える
- 同じ語を違う意味で教えると、「上書き／追記／今のまま」を選べる
- 左上のメニューから、覚えている単語を探したり消したりできる（消すときは2回押す）

## 動かし方

`index.html` をブラウザで開くだけで動く（サーバー不要）。データはそのブラウザの IndexedDB に保存される。

## テスト

`tests/test.html` をブラウザで開くと、回帰テストが走る。
