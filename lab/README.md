# 試験室（lab/）

回答モデルを iPhone で落ちずに動かせる、モデルと動かし方を探すページ。アプリの記憶（IndexedDB）には触れない。Service Worker もこのフォルダは扱わない。

- アプリと同じ部品（`js/llm.js`・`js/rag.js`・`js/models.js`・`js/diag.js`）を使う。試験用の資料と質問は `data.js`。
- 動かし方：CPUだけ／分担（半分の層をGPU）／GPU。仕組みは wllama 3.6.1（llama.cpp の Web 版、MIT）。`../vendor/` に同梱。
- 試験は5つ：読み込み → 短い答え3回 → 検索と連携5問 → 長い資料（約1700字を分けて読む）→ 連続10問（続きの質問を含む）。速さ（最初の文字まで・字/秒）と品質（期待する語の割合・資料との一致率・日本語の割合）を記録する。
- 「検索モデルとの入れ替えも試す」をオンにすると、質問ごとに意味検索のモデル（e5）を載せる → 外す → 回答モデルを載せる、を行う（アプリと同じく、同時には載せない）。
- 段階の記録（`lab-diag-*`）は localStorage に残り、強制終了したら次に開いたとき表示する。質問の本文は記録しない。
- 手順書：`docs/VERIFY-IPHONE.md`
